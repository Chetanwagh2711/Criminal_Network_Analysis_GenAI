# 👁️🗨️ NULLNODE: AI-Powered Criminal Network Analysis System (CNAS)

An autonomous investigative graph intelligence platform designed to ingest multi-source police case narratives (FIRs), call detail records (CDRs), and financial ledgers to map covert criminal syndicates.

### 🌟 Key Capabilities
* **👑 NullNode Identification:** Flags apex kingpins who deliberately stay "off the wire" with zero recorded calls to street operatives.
* **🚚 Cut-Out & Courier Detection:** Uses betweenness centrality algorithms to locate critical hawala bridges and logistics handlers.
* **🔮 Explainable Link Discovery:** Uncovers hidden ties between non-adjacent suspects with plain-language evidentiary rationales.
* **⛓️ Blockchain Chain of Custody:** Cryptographically seals raw evidence with SHA-256 digests, compliant with Section 65B of the Indian Evidence Act / BSA.
* **🕸️ Interactive Command Radar:** Real-time force-directed network graph (Pyvis/Streamlit) with hierarchical top-to-bottom command views.

### 🛠️ Tech Stack
* **Frontend:** Streamlit, Streamlit Components, Custom Cyber UI
* **Network Graph:** Pyvis, NetworkX
* **Data & Extraction:** Pandas, Regular Expressions (E.164, Indian Vehicle Registration, Bank AC)
* **Cryptographic Security:** Hashlib (SHA-256)
